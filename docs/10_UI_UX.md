# UI y UX

## Panel principal
Panel híbrido con indicadores arriba y accesos operativos debajo.

## Patrones
- Tablas con filtros y búsqueda.
- Chips de ingredientes.
- Tarjetas flotantes.
- Panel lateral para detalle rápido.
- Drag & drop documental.
- Semáforos de confianza y validación.
- Acciones masivas para aprobar campos confiables.

## Principio
Reducir captura manual y evitar navegación innecesaria.
