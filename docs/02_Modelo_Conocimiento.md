# Modelo de conocimiento

## Entidades centrales
- Materia prima.
- Nombre comercial.
- INCI.
- CAS/EC.
- Función cosmética.
- Propiedad técnica.
- Compatibilidad.
- Incompatibilidad.
- Restricción.
- Documento fuente.
- Proveedor.
- Formulación.
- Versión de formulación.

## Tipos de dato
- Documental: aparece expresamente en una fuente.
- Inferido: propuesto por el sistema.
- Validado: revisado por una persona autorizada.
- No encontrado.
- En conflicto.

## Regla de trazabilidad
Cada valor técnico debe poder apuntar al documento, página, hoja, celda o sección que lo originó.
